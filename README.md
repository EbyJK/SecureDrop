# SecureDrop 🔒

**SecureDrop** is a simple, sophisticated, full-stack personal information manager integrated with a Telegram Bot. Users can save notes, URLs, documents, and photos directly through a Telegram bot or a web dashboard. The web dashboard provides real-time search, category filtering, statistics, and secure access to saved content.

---

## 🌟 Key Features

1. **Telegram Bot Integration**:
   - Command support: `/start`, `/save`, `/list`, `/search`, `/delete`, `/help`.
   - Direct message processing: Send raw text, URLs, photos, or documents to automatically save them to your account.
   - Account Linking via unique secret pairing tokens (`/start <token>`).

2. **Modern Web Dashboard**:
   - Real-time dashboard statistics: Total Items, Notes, Links, Files, and Items Added This Week.
   - Search & Category filtering (Work, Study, Development, Personal, Links, Files, Other).
   - Full CRUD operations for Notes, Links, and Uploaded Files.
   - Expiring Items: Set automated item expiration (e.g. `2h`, `1d`, `1w`). Cleaned up via NestJS Cron Scheduler.

3. **Security & Authentication**:
   - JWT authentication with secure password hashing (`bcrypt`).
   - Protected REST API endpoints.


## 🗄️ Database Schema

### `users` Table
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique user ID |
| `name` | Varchar | Not Null | User full name |
| `email` | Varchar | Unique, Not Null | Account email |
| `passwordHash` | Varchar | Not Null | Bcrypt hashed password |
| `telegramUserId`| Varchar | Unique, Nullable | Linked Telegram account ID |
| `telegramLinkToken`| Varchar| Unique, Nullable | Temporary pairing token |
| `createdAt` | Timestamp| Default NOW | Creation timestamp |
| `updatedAt` | Timestamp| Default NOW | Update timestamp |

### `items` Table
| Column | Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `id` | UUID | Primary Key | Unique item ID |
| `userId` | UUID | Foreign Key -> users.id | Owner ID |
| `type` | Enum | `NOTE`, `LINK`, `FILE` | Content type |
| `title` | Varchar | Not Null | Item title |
| `content` | Text | Nullable | Text body or URL |
| `fileUrl` | Varchar | Nullable | Public file download URL |
| `fileName` | Varchar | Nullable | Original uploaded file name |
| `fileSize` | Integer | Nullable | File size in bytes |
| `mimeType` | Varchar | Nullable | MIME media type |
| `category` | Enum | `Work`, `Study`, `Development`, `Personal`, `Links`, `Files`, `Other` | Category tag |
| `expiresAt` | Timestamp| Nullable | Expiration timestamp |
| `createdAt` | Timestamp| Default NOW | Creation timestamp |

## ⚙️ Setup & Local Installation

### Prerequisites
- **Node.js**: v18+ 
- **PostgreSQL**: Local or hosted database instance

### 1. Database Setup
Create a PostgreSQL database named `securedrop`:
```sql
CREATE DATABASE securedrop;
```

### 2. Backend Setup
Navigate to the `backend/` directory:
```bash
cd backend
npm install
```

Configure your environment variables in `backend/.env`:
```env
PORT=5000
NODE_ENV=development

# PostgreSQL Database Settings
DB_HOST=localhost
DB_PORT=5432
DB_USERNAME=postgres
DB_PASSWORD=your_postgres_password
DB_DATABASE=securedrop
DB_SYNCHRONIZE=true

# JWT Authentication Secret
JWT_SECRET=securedrop_super_secret_jwt_key_2026
JWT_EXPIRES_IN=7d

# Telegram Bot API Token
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_from_botfather

UPLOAD_DIR=./uploads
```

Start the NestJS backend in development mode:
```bash
npm run start:dev
```
The backend API will run on `http://localhost:5000/api`.

---

### 3. Frontend Setup
Open a new terminal and navigate to `frontend/`:
```bash
cd frontend
npm install
npm run dev
```
The React web dashboard will be available at `http://localhost:3000`.

## 🤖 Telegram Bot Configuration & Account Pairing

1. Open Telegram and search for [@BotFather](https://t.me/BotFather).
2. Send `/newbot` and follow the prompts to create your bot.
3. Copy the HTTP API token generated by BotFather and paste it into `backend/.env` under `TELEGRAM_BOT_TOKEN`.
4. Restart your NestJS backend.
5. Log into your SecureDrop Web Dashboard at `http://localhost:3000`.
6. Go to **Settings** -> **Telegram Bot Integration**.
7. Click **Generate Telegram Link Token**.
8. Send `/start <token>` to your Telegram bot. Your Telegram account is now paired!

## 📡 REST API Reference

### Authentication (`/api/auth`)
- `POST /api/auth/register` — Register a new account
- `POST /api/auth/login` — Login & retrieve JWT access token
- `GET /api/auth/me` — Get current logged-in user details (Protected)
- `POST /api/auth/telegram-token` — Generate 1-time Telegram pairing token (Protected)
- `POST /api/auth/unlink-telegram` — Disconnect Telegram account (Protected)

### Items (`/api/items`)
- `GET /api/items` — Retrieve all items (supports `?search=`, `?category=`, `?type=`)
- `GET /api/items/stats` — Retrieve dashboard statistics
- `GET /api/items/:id` — Get single item details
- `POST /api/items` — Create a new item
- `PATCH /api/items/:id` — Update an existing item
- `DELETE /api/items/:id` — Delete an item

### Files (`/api/files`)
- `POST /api/files/upload` — Upload file attachment (Protected)
- `GET /api/files/download/:filename` — Download file attachment
